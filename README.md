# دستیار هوشمند مدیریت مصرف آب (خانگی و کشاورزی)
پروژه‌ای نوآورانه برای شرکت در جشنواره خوارزمی

## 📌 درباره پروژه
این سامانه یک دستیار هوشمند و مقیاس‌پذیر است که با دریافت داده‌های اقلیمی (مانند دمای هوا) و نوع کاربری (خانگی یا کشاورزی)، میزان نیاز آبی بهینه را محاسبه کرده و راهکارهای علمی جهت کاهش هدررفت آب ارائه می‌دهد.

## 🚀 ویژگی‌های کلیدی
- **تحلیل اقلیمی آنی:** محاسبه دقیق مصرف آب بر اساس دما و نوع کاربری.
- **معماری PWA (Progressive Web App):** قابلیت نصب روی سیستم‌عامل‌های مختلف (ویندوز، اندروید و...) بدون نیاز به استورهای رسمی.
- **قابلیت کارکرد آفلاین:** استفاده از Service Worker برای دسترسی بدون اینترنت.
- **ذخیره‌سازی محلی (LocalStorage):** حفظ تاریخچه محاسبات کاربر روی دستگاه.
- **طراحی واکنش‌گرا (Responsive):** بهینه‌سازی شده با فریم‌ورک Tailwind CSS.

## 🛠 فناوری‌های استفاده شده
- **HTML5 & Tailwind CSS** (رابط کاربری و طراحی مدرن)
- **JavaScript (ES6+)** (منطق محاسباتی و مدیریت داده‌ها)
- **Service Worker & Web Manifest** (فناوری PWA)
- **GitHub Pages** (میزبانی ابری امن با پروتکل HTTPS)
